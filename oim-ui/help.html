Help Center

Configure the service for your organization before connecting real callers.

First setup

  1. Sign in with the one-time administrator credentials created at first launch.
  2. Add a customer account and set its AI greeting, voice, and working hours.
  3. Add published knowledge articles in the languages your callers use.
  4. Configure OpenAI Realtime and, if needed, Google Calendar and Telegram.
  5. Connect an inbound SIP route only after the PBX and webhook have been configured.

Knowledge base

Use the prompt and language templates in the dashboard to prepare business-specific information. Review prices, hours, booking rules, and cancellation policies before publishing. Only published documents are supplied to the voice agent.

Keep each language version aligned. Do not include real caller information in public issue reports.

Integrations

Provider credentials belong in the protected server environment or administrator settings. Never place API keys, SIP passwords, OAuth secrets, call recordings, or customer exports in this repository.

Support contact details are set by the operator who deploys this software.
